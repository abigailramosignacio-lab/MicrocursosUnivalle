LO QUE SE USA: MVC

JUSTIFICACION: por qué MVC
Elegimos MVC porque el sistema tiene tres roles y cada uno necesita sus propias rutas y acciones. Con MVC cada controlador agrupa una responsabilidad; por ejemplo, un controlador para el administrador y otro para el suscriptor. Además, la inscripción debe verificarse en el servidor aunque alguien conozca la URL, y el controlador es el lugar natural para validarlo antes de mostrar una lección. Por último, separar Modelo, Vista y Controlador nos permitió repartir el trabajo entre dos personas sin editar los mismos archivos.
